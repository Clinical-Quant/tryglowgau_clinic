A note about this website.

Aurum Aesthetics is a demo clinic website. Please read this page carefully before drawing conclusions about the services, results, or team it portrays.

This is a demo clinic website used to demonstrate Glowgau’s AI clinic assistant. It is not a real medical practice and does not provide medical advice.

What this site is

This website is a demonstration of how an aesthetic clinic could use Glowgau’s AI clinic assistant to support prospective clients — answering common questions about treatments, gathering information about client goals, and helping visitors request a consultation through a natural, conversational interface.

The website itself is built as a polished reference example: an aesthetic clinic experience a real clinic could use as inspiration, with the Glowgau assistant embedded in place of a static contact form.

What this site is not

  • It is not a real medical practice. No clinic operates at this location; no treatments are performed; no client is seen by a practitioner.
  • It does not provide medical advice. Nothing on this website should be taken as medical advice, diagnosis, or a recommendation for any specific treatment.
  • The “clinic team” members shown are illustrative roles. Names, monograms, and roles are placeholders for demo purposes and do not represent real, qualified practitioners.
  • No treatments have been performed on real clients. Where the site describes treatments, it describes categories of treatment — not verified outcomes for any individual.
  • No testimonials are shown. We avoid fabricated reviews entirely; a real clinic’s reviews would never be invented for marketing.

About the Glowgau widget

On this site, a placeholder appears where the Glowgau AI clinic assistant would normally load. The widget is the centerpiece of how Glowgau helps clinics convert more website visitors into consultations while giving prospective clients a friendly, knowledgeable first touchpoint.

To learn more about Glowgau, please visit glowgau.com.

Why this demo exists

The purpose of this site is to let prospective clinics see Glowgau working in a real-looking environment — to feel the rhythm of how the assistant behaves and how it would integrate into a polished, professional clinic brand.
